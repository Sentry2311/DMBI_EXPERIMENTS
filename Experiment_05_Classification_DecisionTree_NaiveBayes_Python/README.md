# Experiment 05: Classification Using Python (Inbuilt vs User-Defined Functions)

## Aim
To implement and compare classification algorithms (Decision Tree and Naïve Bayes) using Python inbuilt library functions and custom user-defined functions on the Student Result Classification Dataset.

## Contents
1. **Document:** [`DMBI_EXP-5_40.docx`](DMBI_EXP-5_40.docx) (Updated with GitHub link at the end).
2. **Dataset:** [`student_result_classification_dataset.csv`](student_result_classification_dataset.csv) (500 records of students with demographics, study hours, attendance, and exam pass/fail results).
3. **Program Code:** [`student_classification_inbuilt_vs_custom.py`](student_classification_inbuilt_vs_custom.py) (Contains full implementations of inbuilt scikit-learn models and custom tree/probabilistic algorithms).

## Execution
```bash
python student_classification_inbuilt_vs_custom.py
```
