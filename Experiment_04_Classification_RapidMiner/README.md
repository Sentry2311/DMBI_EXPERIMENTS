# Experiment 04: Classification Using RapidMiner (Decision Tree & Naïve Bayes)

## Aim
To explore RapidMiner and implement classification models — Decision Tree and Naïve Bayes — on the Movie Ticket Booking dataset to predict whether a booking will be Successful or Unsuccessful, and compare model performance.

## Contents
1. **Document:** [`DBMI_exp4_40.docx`](DBMI_exp4_40.docx) (Updated with GitHub link at the end).
2. **Dataset:** [`movie_ticket_booking_dataset.csv`](movie_ticket_booking_dataset.csv) (Features: Genre, Show_Time, Screen_Type, Ticket_Price, Tickets_Booked, Customer_Age, Payment_Method, booking_status).
3. **RapidMiner Process:** [`Movie_Ticket_Classification_Process.rmp`](Movie_Ticket_Classification_Process.rmp) (Visual workflow XML for Altair AI Studio).
4. **Python Implementation:** [`classification_models.py`](classification_models.py) (Python code replicating the Decision Tree and Naïve Bayes training and evaluation).
