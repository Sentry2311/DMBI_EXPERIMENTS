# Experiment 03: Exploratory Data Analysis and Visualization Using Python

## Aim
To perform exploratory data analysis (EDA) and data visualization on the Movie Ticket Booking system using Python.

## Contents
1. **Document:** [`DMBI_exp3_40.docx`](DMBI_exp3_40.docx) (Updated with GitHub link at the end).
2. **Dataset:** [`Movie_Ticket_Booking_EDA_Dataset.csv`](Movie_Ticket_Booking_EDA_Dataset.csv) (Contains Booking_ID, Movie, City, Tickets, Ticket_Price, Total_Amount, Booking_Rating).
3. **Program Code:** [`eda_and_visualization.py`](eda_and_visualization.py) (Calculates Central Tendency, Dispersion, Correlation, and Group-by analytics).

## Execution
```bash
python eda_and_visualization.py
```
