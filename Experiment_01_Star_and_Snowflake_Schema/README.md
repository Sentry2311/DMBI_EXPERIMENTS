# Experiment 01: Design Star and Snowflake Schema for Movie Ticket Booking System

To design two Star Schemas (Ticket Sales and Revenue) and a normalized Snowflake Schema for a Movie Ticket Booking system using suitable Fact tables and Dimension tables.
