# Experiment 07: K-Means Clustering Using RapidMiner

## Aim
To prepare a RapidMiner workflow that clusters the UCI Seeds records into three groups using all seven numeric kernel measurements, after replacing missing values and applying Z-score normalization.

## Contents
1. **Document:** [`DBMI_7_40.docx`](DBMI_7_40.docx) (Updated with GitHub link at the end).
2. **Dataset:** [`seeds_7_features.csv`](seeds_7_features.csv) (UCI Seeds dataset).
3. **RapidMiner Process:** [`Seeds_KMeans_Experiment.rmp`](Seeds_KMeans_Experiment.rmp) (Altair AI Studio workflow with Select Attributes, Replace Missing Values, Normalize, K-Means k=3, and Cluster Model visualizers).
4. **Python Replication Code:** [`rapidminer_kmeans_seeds.py`](rapidminer_kmeans_seeds.py) (Python script reproducing the exact normalized centroids).
