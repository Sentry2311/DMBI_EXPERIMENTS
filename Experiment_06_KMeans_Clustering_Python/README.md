# Experiment 06: Implementation of K-Means Clustering Using Python

## Aim
To implement the K-Means clustering algorithm using Python on the Seeds dataset and analyze clustering performance using the Elbow Method, Silhouette Score, and Davies-Bouldin Index.

## Contents
1. **Document:** [`DMBI_6_40(11) (1).docx`](DMBI_6_40(11)%20(1).docx) (Updated with GitHub link at the end).
2. **Dataset:** [`seeds_7_features.csv`](seeds_7_features.csv) (210 wheat grain instances with 7 morphological geometric features).
3. **Program Code:** [`kmeans_clustering_seeds.py`](kmeans_clustering_seeds.py) (Python script calculating inertia, optimal K, centroids, and evaluation metrics).

## Execution
```bash
python kmeans_clustering_seeds.py
```
